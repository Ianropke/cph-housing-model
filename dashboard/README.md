# CPH Housing Dashboard

React/Vite frontend for the Copenhagen Housing Model. The production build is static: it reads `public/data/latest_pipeline.json`, generated by `scripts/daily_pipeline.py`.

## Local commands

```bash
npm ci
npm run dev
npm run lint
npm run build
```

The local Vite middleware in `vite.config.js` is development-only. It is not a production API or a data fallback.

## Data contract

`src/context/CityProvider.jsx` validates the payload before rendering. The dashboard refuses to display model values when the payload is invalid, older than 48 hours, not marked live, or when the DST observation period/index does not match the forecast. See `docs/model_governance.md` and `dashboard/src/data/pipelineSchema.js` for the contract.

The ML crash probability is intentionally rendered as unavailable until the model has point-in-time, out-of-sample validation. EWI and Market Risk Score remain separate index outputs and must not be read as percentage probabilities.
